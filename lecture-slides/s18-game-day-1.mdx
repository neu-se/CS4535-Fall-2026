## Four Rules

<div style={{fontSize: '0.75em', textAlign: 'left'}}>

1. **Read-only until you can explain it.** Use `psql-ro` until you can tell your partner the cause *and* how many were affected. Then `psql-rw`
2. **Log everything in `~/gameday-1/timeline.md`:** the time, the query, and what it told you
3. **Repairs run inside `BEGIN`.** Check the row count before you `COMMIT`
4. **Don't reset or stop the stack.** Production doesn't have a reset button

</div>

<aside className="notes">
Rule 2 is the one they'll skip, and the postmortem is built from it. Say that at minute 15 too.

Rule 4: a reset would make the symptom go away and destroy the evidence at the same time. Don't explain more than that.

> **Transition:** The clock.

## The Worksheet: Predict, Then Run

<div style={{fontSize: '0.68em', textAlign: 'left'}}>

One page, on paper, no AI. Each prediction goes on paper **before** you run the thing it predicts.

1. **The repair** (inside `BEGIN`): predicted rows, what psql said, and why they differ if they do. Decide before you `COMMIT`
2. **Your account** (minute 40): the cause, how many and which question that answers, the action you took
3. **Predict the AI** (before `gameday-postmortem`): its number, and what it'll get wrong
4. **Run it, then check:** were you right, what it actually got wrong, and the action item you'd ship first

</div>

<aside className="notes">
Show this at minute 0 with the handout of the sheet, and again at minute 40. The predictions are the point: A row count that surprises them before COMMIT is the most useful thing that can happen to them today, and a prediction about the AI keeps them from anchoring on whatever the draft says.

> **Transition:** At minute 45, the postmortem.
</aside>

## Minute 45: Predict, Then Run the Postmortem

<div style={{fontSize: '0.75em', textAlign: 'left'}}>

Fill in **block 3** first. Then:

```bash
gameday-postmortem
```

- Runs Claude Code with the same prompt for everyone: read it in `~/gameday-1/POSTMORTEM-PROMPT.txt`
- It reads your `timeline.md`, checks facts with read-only queries, and writes `~/gameday-1/POSTMORTEM.md`
- It takes two to three minutes. Then **block 4**: check it against your prediction

</div>

<aside className="notes">
Check block 3 is filled in before anyone presses enter. If someone's Claude Code isn't logged in, they run `claude` once to log in, or read their partner's draft. A thin `timeline.md` produces a thin draft. That's worth pointing out to whoever skipped rule 2. Collect sheets at minute 60.
