**Content this needs to carry, roughly in order:**
- Where things live: `app/` (App Router), `components/`, `hooks/`, `lib/`. The treemap from s01 is the map; this is the walkthrough.
- **Generated types.** `npm run client-local` after every migration, never hand-edit `SupabaseTypes.d.ts`. Already flagged twice, in s02's three gotchas and in s03. This is where it gets explained rather than asserted.
- **TableController and realtime.** How a row gets from Postgres to a component without the component polling for it.
- **Data access conventions.** RPC-first, per s01's "Prefer RPCs" slide, which says this is the single convention most first PRs violate. Review sends back a route handler that queries Supabase directly.
- **The gradebook table as the worked case**, because every one of them is inside it this week. The `groupedColumns` memo is the thing they are replacing, and there are three copies of the slug heuristic, not one.
